# My Finances

This project is a simple finance tracker built with React and TypeScript using Vite.

## Features
- Record income and expenses with description, amount, date and currency (COP, USD, EUR).
- View transaction history filtered by currency.
- Automatic balance calculation for each currency.
- Language selector (English/Spanish).
- Theme selector (Light/Dark).
- Responsive interface styled with Tailwind CSS.

## Getting Started

To run the project you need Node.js installed. Install dependencies and start the development server:

```bash
npm install
npm run dev
```

The app will be available at `http://localhost:3000`.
